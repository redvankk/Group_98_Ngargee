# How It Works

The RMIT Clubs Assistant uses **Retrieval-Augmented Generation (RAG)** to provide answers based on information contained in its club knowledge base.

### 1. You ask a question

Ask naturally instead of searching using exact keywords.

### 2. Relevant information is retrieved

The system searches club information to identify content related to your question.

### 3. An answer is generated

The chatbot uses the retrieved information to create an easy-to-understand response.

### 4. Sources are provided

Where available, the assistant shows the source used so you can verify the information yourself.

The assistant can only answer using information available in its current knowledge base.

If information is missing or uncertain, it will tell you instead of intentionally creating unsupported information.

For the most recent information, always check the linked official RMIT or RUSU club page.

# About the Project

The **RMIT Clubs Assistant** is a student-developed project designed to explore how Retrieval-Augmented Generation and semantic search can improve access to student club information.

The project investigates whether a conversational interface can make club discovery easier while improving the relevance and reliability of information provided to students.

The system combines:

* Natural Language Processing
* Semantic search
* Vector embeddings
* Retrieval-Augmented Generation
* Large Language Models
* Web application technologies

# Frequently Asked Questions

### Is this an official RMIT service?

This chatbot is a student-developed academic project and should not be considered an official RMIT service unless otherwise stated.

### Where does the information come from?

The knowledge base contains club information collected from approved or publicly available RMIT/RUSU sources used for the project.

### Can the chatbot recommend clubs?

Yes. You can describe your interests and the chatbot can retrieve clubs that appear relevant based on available information.

### Can the chatbot make mistakes?

Yes. AI-generated responses may occasionally contain errors. Users should verify important information using the linked source.

### Does the chatbot know everything about RMIT?

No. It is designed specifically around the information included in the project's club knowledge base.

### Is my conversation stored?

Conversation and feedback handling depends on the final system design. Any stored information should be handled according to the project's privacy and data-management requirements.
